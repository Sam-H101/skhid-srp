# The addresses of resources.db's patches: what the updater takes (`ok`)
# and refuses (`bad`) as a patch's `url` in the server's list
# (client/updater/logic/src/url.rs `patch`, through patches.rs
# `parse_list`), and so what srp-game-data takes as a patch's URL
# (srp-026g/crates/resources-db/src/server.rs `is_url`). The tests of both
# read this file: a URL srp-game-data takes would be refused on the players'
# computers otherwise, and their PLAY would stay off.
#
# A line is `ok <url>` or `bad <url>`: the URL is the rest of the line after
# the first space (`bad` alone: the empty URL). In it {SP} {TAB} {CR} {LF}
# {NUL} {DEL} stand for those bytes and {a*N} for N letters a.
