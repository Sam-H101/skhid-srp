# srp: the server for client 0.100b

> **Version scope: everything on this page is for client 0.100b** (early
> 2013). Not live; the public servers run 0.21d and 0.26g. 0.100b is a
> different design from 0.21d: **server-authoritative** (the server runs
> combat, spawns, batteries, traps), where 0.21d is lockstep (clients
> simulate; the server relays).

`srp-0100b` is the upstream 0.100b server (github.com/srp-survarium/srp, with
its pull requests 28 and 22 merged) plus the game-mode work of 2026-10-09 and
2026-10-10 described below.

## What it has (322 tests pass)

- **Match lifecycle**: the stock client gets controls at `inprocess`; matches
  end at `match_finished` and return to the lobby.
- **Batteries** (`gather_victory_items`) and team spawns from the map's
  `projects/<map>/server_project.lua` in `resources.db` (level_03_evn: 26
  battery spawners, 2 containers, 43 respawn points). The client never sends
  take/put: the server decides from the use bit 0x10000000 and the position,
  with a 200 ms release delay because the client flickers that bit.
- **Real combat** (`combat/`): the weapon FSM port, ballistics, damage,
  armour, penetration, hitboxes, lag compensation, medkits, recoil that
  settles every tick (the vostok reconstruction got this wrong; the binary
  was right), aim sway (`breath_vibration_calculator`).
- **Traps** (placing, firing, defusing, timers, late joiners).
- **Transport**: per-frame packing ≤ 256 B, resend after 500 ms, a send cap
  (the client's pool is 8192 × 300 B packets; floods crash it), stalled
  alt-tabbed clients skip queued moves.
- **Time sync** (each 0x45 answered).
- **Late join**: spawns, 0x9E damage models, a 0x9D world resync (console only;
  it crashed clients when a spawn named a non-default weapon, fixed).
- **Lobby**: equip by count, prices from the 2013 wiki, purchases charge money,
  rewards (kill 10 points, steal 35, money 100 for finishing + 100 per kill,
  start money 20,000, the 2015 level table), supplies from a per-match pool,
  queue and online counters (`#pc`/`#mc`/`#q` chat notices), sessions with
  presence pings (UDP 25100), friends and ignore lists.
- **Login cert:** the original expired in 2014. It is re-issued with the same
  key until 2037 (`certs/`), and must also replace the game's
  `resources/ssl/survarium_login_server.crt` (the old one is kept as
  `.expired-2014`).

## Not done or not verified

- Hits between two real clients are not live-checked. Rewards, supplies and
  the session features were never seen in the real client.
- Base capture and anomalies: no map in this build has the data.
- A floating weapon after a player leaves.
- The skills tree is refused (it used to panic the lobby connection).

## Gotchas

- Restarting srp while a client is signed in loses its session. After the next
  match the client is stuck on "disconnected from lobby": restart the game
  with every srp restart.
- Don't `cargo build --workspace` while `srp.exe` runs (it can't overwrite
  the exe).
- Match-server tests need `SRP_RESOURCES_DB=Survarium/resources.db`,
  or the data tests quietly pass without running.
- Standing jumps double-hop at high fps (client-side; V-sync helps).
- Tests: run the servers with `SRP_MATCH_TIME_SECS=60` and drive them with
  the scripts in `tools/re-kit/v0100b/e2e/`, then confirm in the real game.
